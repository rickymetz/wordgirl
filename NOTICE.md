by field of endeavour. GitHub will describe it as non-standard, some
contributors decline to work on non-OSI projects, and package registries

the "fork freely, don't sell it" rule.

you publish, so nobody has to guess which one is the original.

## Third-party components

### Word list

`src/lib/words/dictionary.txt` is generated by
`scripts/build-dictionary.mjs` from two sources:

- **ENABLE** — the Scrabble tournament word list, public domain.
  Supplies every accepted word.
- **FrequencyWords** (hermitdave), content licensed **CC-BY-SA-4.0**,
  derived from OpenSubtitles. Used only to rank ENABLE words into the
  required and bonus tiers; none of its text is redistributed.

The frequency data earns a credit either way, and it has it. Whether a
tier assignment derived from that ranking is a "derivative work" carrying
CC-BY-SA's share-alike obligation is a genuinely open question — word
frequencies are arguably uncopyrightable facts — and if it is, share-alike
would sit awkwardly beside a noncommercial licence, since CC-BY-SA forbids
adding restrictions. Worth a lawyer's read before anyone commercialises a
fork. Regenerating the tiers from a permissively licensed frequency list
would remove the question entirely.

## Analytics

The deployed site uses Fathom Analytics. A fork that deploys its own copy
should replace the `data-site` value in `index.html` with its own, or drop
the script tag — otherwise it reports into this site's dashboard.
