Backwords is a mirror game. The game gives you a set of letters. You put letters on the left side of a mirror. The mirror shows the other letters. The day is complete when you use all the letters.

## How to play

There are two types of row:

- **Pair.** A pair is a word that makes a different word in the opposite direction. An example is STOP and POTS. Put one word on the board. The mirror shows the other word. A pair uses all the letters of the word. The two directions are correct.
- **Palindrome.** A palindrome is a word that is the same in the two directions. An example is LEVEL. Put only the first half of the letters. The mirror completes the word. If the word has an odd number of letters, the center letter goes on the mirror line.

Each day, the set of letters has more than one correct solution. The solutions have different numbers of rows. Thus you have a real choice of strategy.

Some rows have a star symbol. These rows use only letters that are symmetrical in a mirror. These letters are A, H, I, M, O, T, U, V, W, X, and Y. A real mirror shows these rows correctly.

## How the game makes a puzzle

The game first makes a word list from the usual dictionary words:

- The list contains each word that makes a different correct word in the opposite direction.
- The list contains each palindrome. Short palindromes come first.

Each row has a cost. The cost is the set of letters that the row uses. The generator and the game use the same word list. Thus each puzzle has a solution with the same rules that you play with.

The generator makes the puzzle in these steps:

1. The generator selects one pair with four letters or more. Thus each day has one large row.
2. The generator adds random rows until the letter set has 8 to 12 letters.
3. The generator finds all the solutions for the letter set. The maximum is 40 solutions. The search subtracts the cost of each row from the letter set. A solution is correct when the letter set becomes empty.
4. The generator keeps the puzzle only when:
   - There are two solutions or more.
   - The solutions have two different row counts or more.

   The generator prefers three solutions or more. The maximum is 400 tries.

The puzzle contains only the letter set and some data about the solutions. When you play, the game examines your rows with the word list and simple letter counts. The code is in `src/games/backwords/engine/lexicon.ts` and `generator.ts`.
