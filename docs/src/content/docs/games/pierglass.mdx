Pierglass is a mirror game. The game gives you a set of letters. You put letters on the left side of a mirror. The mirror shows the other letters. The day is complete when you use all the letters.

## How to play

There are two types of row:

- **Pair.** A pair is a word that makes a different word in the opposite direction. An example is STOP and POTS. Put one word on the board. The mirror shows the other word. A pair uses all the letters of the word. The two directions are correct.
- **Palindrome.** A palindrome is a word that is the same in the two directions. An example is LEVEL. Put only the first half of the letters. The mirror completes the word. If the word has an odd number of letters, the center letter goes on the mirror line.

Each day, the set of letters has more than one correct solution. The solutions have different numbers of rows. Thus you have a real choice of strategy.

Some rows get a star (✦). These rows use only the letters A, H, I, M, O, T, U, V, W, X, and Y. These letterforms are symmetrical. Try it: hold your telephone to a real mirror, and a star row still reads correctly. The game counts your star rows for the day and for your lifetime statistics.

## How the game makes a puzzle

The game first makes a word list from the usual dictionary words:

- The list contains each word that makes a different correct word in the opposite direction.
- The list contains each palindrome. Short palindromes come first.

Each row has a cost. The cost is the set of letters that the row uses. The generator and the game use the same word list. Thus each puzzle has a solution with the same rules that you play with.

The generator makes the puzzle in these steps:

1. The generator selects one pair with four letters or more. Thus each day has one large row.
2. The generator adds random rows until the letter set has 8 to 12 letters. This band is a measured tuning decision. The first version used 12 to 16 letters. With that band, the most frequent row appeared in 52 percent of the days' solution spaces. The smaller band cuts this to 37 percent. A measurement over 90 daily puzzles found 0 generation failures, with a maximum of 26 tries.
3. The generator finds all the solutions for the letter set. The maximum is 40 solutions. The search subtracts the cost of each row from the letter set. A solution is correct when the letter set becomes empty.
4. The generator keeps the puzzle only when:
   - There are two solutions or more.
   - The solutions have two different row counts or more.

   The generator prefers three solutions or more. The maximum is 400 tries.

The puzzle contains only the letter set and some data about the solutions. When you play, the game examines your rows with the word list and simple letter counts. The code is in `src/games/pierglass/engine/lexicon.ts` and `generator.ts`.

## The mathematics

### The puzzle is a multiset partition

The bank is a multiset of letters. A multiset is a set in which an item can occur more than one time. Each row has a cost $c_i$, also a multiset. A solution is a set of rows whose costs sum to the bank exactly:

$$
\sum_{i \in S} c_i = B
$$

Here $B$ is the bank and $S$ is the set of selected rows. No letter can remain. No letter can be missing. This problem generalizes exact cover: exact cover is the special case in which each letter occurs one time. The decision problem for exact cover is NP-complete (Karp, 1972). Thus the general form of this puzzle is at least as hard.

### One worked example

Take this bank of 8 letters: E, N, O, O, P, S, T, Y. One solution has three rows:

- The pair STOP. The mirror shows POTS. The cost is $\{O, P, S, T\}$.
- The palindrome NOON. You place the half "NO". The cost is $\{N, O\}$.
- The palindrome EYE. The length is odd. You place "EY", and the Y sits on the mirror line. The mirror completes the last E. The cost is $\{E, Y\}$.

The three costs sum to the bank exactly:

$$
\{O,P,S,T\} + \{N,O\} + \{E,Y\} = \{E,N,O,O,P,S,T,Y\}
$$

This is the central equation, verified by hand.

A parity fact hides here. A pair costs the full word length. A palindrome of length $n$ costs only $\lceil n/2 \rceil$ letters. Thus a palindrome is often the only way to spend an odd number of remaining letters.

### Why the search stays fast

Two limits make the search small:

- The bank has a maximum of 12 letters.
- Each row costs a minimum of 1 letter. The smallest cost comes from the palindrome MM, which places only one M.

Thus a solution has a maximum of 12 rows, and the recursion depth has the same limit. In practice, solutions have 2 to 5 rows, because most costs are 2 letters or more. The search also goes through the row list in one fixed order. A branch can only select rows after its current position. Thus each solution set is counted one time, without permutations.

### The mirror letters

The board draws all the letters as capitals. The star rows use only the letters A, H, I, M, O, T, U, V, W, X, and Y. The glyphs of these capitals do not change under reflection across a vertical axis. No other capital is the mirror image of a different capital — the lowercase tricks with b, d, p, and q do not exist among capitals. Thus a row is a star row exactly when a real mirror renders the drawn reflection.
