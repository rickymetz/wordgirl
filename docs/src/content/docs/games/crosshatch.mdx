Crosshatch is a crossword game. The game shows a small crossword frame. Some letters are given. Many different sets of words agree with the frame. Your goal is to find all the words that are possible.

## How to play

1. Put letters in the frame. Each line must make a word from the dictionary.
2. Make sure that the words agree with the given letters.
3. Submit the completed frame. The game keeps each new word from the frame.

A word cannot occur two times in one frame. Progress counts words, not frames. One good frame can bank several words at one time, so you never have to re-enter almost equal frames.

## The two boards

Each day has two boards: Normal and Hard. The day is complete when you find all the words on both.

The Hard board is not a longer board. It has about the same number of words. Every line has five letters, and the frames have more crossings. The result is that a smaller share of each line is given to you at the start: 43 percent on the Hard board against 54 percent on the Normal board, measured over 120 days. So each word is harder to think of, and the day does not take longer to finish.

Days before 15 August 2026 have one board only. The Hard board did not exist then, and a day that was finished at the time stays finished.

## How the game makes a puzzle

The game has eight Normal frame shapes: h, ring, comb, rake, stairs, cross, lattice, and zipper. Each shape has 3 to 5 word slots. Each slot has 3 to 5 letters. The Hard board has its own five shapes: hash, ring5, lattice5, comb5, and grid5. Each of these has 4 or 5 slots, and every slot has 5 letters. All the shapes are in a grid of 5 by 5 cells, so the Hard board is no harder to tap than the Normal one. Both lists are frozen, and each is a separate list. The daily number points into the list for that board.

The generator makes the puzzle in these steps:

1. The generator selects a shape. Then it fills the shape with words. It fills the slot with the fewest possible words first. It examines a maximum of 40 words for each slot.
2. The generator puts one given letter in each slot. A given letter must not complete a slot.
3. The generator finds all the sets of words that agree with the given letters. The maximum is 200 sets. A count of more than 200 sets shows that the frame is too open.
4. The generator adds more given letters until the puzzle is correct. A correct puzzle obeys these limits:
   - The puzzle has 10 to 22 different words.
   - A maximum of one slot has only one word.
   - No slot has more than 8 words.

   If the puzzle is not correct after 6 more letters, the generator starts again. The maximum is 300 tries.

## The mathematics

### The puzzle is a constraint satisfaction problem

Crosshatch is a constraint satisfaction problem (CSP):

- The variables are the word slots.
- The domain of a slot is the set of dictionary words with the correct length.
- One constraint applies at each shared cell: the two words must have the same letter there.
- One global constraint applies: a word cannot occur two times in one frame.

Crossword fill is NP-hard in the general case. The search space for one frame is large. A frame with four slots and 1,000 possible words for each slot has $1000^4 = 10^{12}$ combinations — one trillion. The game examines your frame instantly because it did the hard thinking before you woke up. Two properties keep the generation fast. The frames are small and frozen. The search fills the most constrained slot first (the MRV heuristic). This order finds conflicts early and cuts the search tree.

### The solution space

The generator counts the full solution space with an exhaustive search. The count of word sets must stay below 200. This limit bounds the number of solutions, and thus the information in the frame: at most $\log_2 200 \approx 7.6$ bits separate the given letters from a full answer. A frame with too many solutions gives the player no traction. The given letters shrink the space step by step. Each added letter removes the word sets that disagree with it.

### Why the answer check is fast

The puzzle object contains the full list of word sets. The game makes this list one time. When you send a frame, the game compares it with the list. The expensive search occurs one time, before you play. The code is in `src/games/crosshatch/engine/generator.ts` and `shapes.ts`.
