Crosshatch is a crossword game. The game shows a small crossword frame. Some letters are given. Many different sets of words agree with the frame. Your goal is to find all the words that are possible.

## How to play

1. Put letters in the frame. Each line must make a word from the dictionary.
2. Make sure that the words agree with the given letters.
3. Send the completed frame. The game keeps each new word from the frame.

A word cannot occur two times in one frame. Progress counts words, not frames. Thus you do not send almost equal frames again and again.

The day is complete when you find 90 percent of the words. There is always a margin of two words or more. Thus one difficult word cannot stop your streak. The formula for the target is:

```
target = max(1, min(ceil(0.9 * total), total - 2))
```

## How the game makes a puzzle

The game has eight frame shapes: h, ring, comb, rake, stairs, cross, lattice, and zipper. Each shape has 3 to 5 word slots. Each slot has 3 to 5 letters. All the shapes are in a grid of 5 by 5 cells. The list of shapes is frozen. The daily number points into this list.

The generator makes the puzzle in these steps:

1. The generator selects a shape. Then it fills the shape with words. It fills the slot with the fewest possible words first. It examines a maximum of 40 words for each slot.
2. The generator puts one given letter in each slot. A given letter must not complete a slot.
3. The generator finds all the sets of words that agree with the given letters. The maximum is 200 sets. More than 200 sets shows that the frame is too open.
4. The generator adds more given letters until the puzzle is correct. A correct puzzle has 10 to 22 different words. A maximum of one slot can have only one word. No slot can have more than 8 words. If the puzzle is not correct after 6 more letters, the generator starts again. The maximum is 300 tries.

## Why the answer check is fast

The puzzle object contains the full list of word sets. The game makes this list one time. When you send a frame, the game compares it with the list. This comparison is fast. The game does not do a search when you play. The code is in `src/games/crosshatch/engine/generator.ts` and `shapes.ts`.
