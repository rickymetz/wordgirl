Serpentine is a path game. A line of poetry is hidden in a grid of letters. You draw one continuous path through the grid. The path must go through each cell one time. The path shows the poem.

## How to play

1. Start at the first letter of the text.
2. Move to an adjacent cell. The eight cells around a cell are adjacent. Diagonal movement is permitted.
3. Go through each cell one time.

The game has two modes each day. Haiku mode has a short Japanese poem in translation. Poem mode has a longer line from an English poem. The two modes have the same theme each day.

The game accepts each correct path. A correct path obeys three rules:

- The path is continuous.
- The path goes through each cell one time.
- The path shows the correct text.

The check is in `src/games/serpentine/engine/validation.ts`.

## The poems

The poems come from seven theme groups. The themes are water, creatures, sky, seasons, time, beauty, and wind. All the poems are in the public domain. There are 76 haiku from poets such as Basho, Issa, and Buson. There are 414 English lines from poets such as Dickinson, Byron, Keats, Blake, and Shakespeare.

## How the game makes a puzzle

The generator makes the puzzle in these steps. The code is in `src/games/serpentine/engine/puzzles.ts`.

1. The generator removes all the characters that are not letters. It counts the letters.
2. The generator selects the best grid. It examines each grid to a maximum of 8 rows and 10 columns. The best grid has the fewest empty cells. When two grids are equal, the more square grid is better.
3. The generator closes the empty cells. It closes corner cells first, then edge cells, then center cells. The open cells must stay connected. The generator examines the connection with a breadth-first search. The maximum is 50 tries.
4. The generator makes the path. It starts at a random open cell. It always moves to the adjacent cell that has the fewest free adjacent cells. This method is the Warnsdorff rule. If the path stops before the last cell, the generator starts a new path. The maximum is 200 tries.
5. If no path is found, the generator uses a simple alternative. This path goes through the rows in alternate directions. This path is always possible on these grids.
6. The generator writes the letters of the poem along the path.

## The mathematics

### The path is a Hamiltonian path

A path through all the cells, one time each, is a Hamiltonian path. The decision problem "does this graph have a Hamiltonian path?" is NP-complete. A general algorithm with a time guarantee is not known.

### Why the grid makes it easy

The grid is a king graph. The name comes from the chess king. Each cell connects to the eight cells around it. An interior cell has degree 8. This graph is much denser than a grid with only four directions. On dense graphs of this size, a maximum of 80 cells, a random search finds a Hamiltonian path with high probability.

### The Warnsdorff rule

The path search is a greedy walk with one rule. From the current cell $v$, go to the free adjacent cell $u$ with the fewest free adjacent cells:

$$
u = \arg\min_{u \in N(v),\ u \text{ free}} \big|\, N(u) \cap \text{free} \,\big|
$$

The idea: go to the cells that are almost isolated first. A cell with few free connections becomes unreachable easily. The rule comes from the knight's tour problem (Warnsdorff, 1823). The search has no backtracking. A dead end starts a new walk from a new random cell. The random tie decision makes each new walk different.

### The guaranteed alternative

If 200 walks fail, the generator makes a boustrophedon path. The path goes through row 1 to the right, row 2 to the left, and so on. Each step in this path is a king move. Thus the path is correct by construction on these boards. The generator cannot fail.

### The grid selection

For a text with $n$ letters, the generator minimizes this score over all grids to 8 by 10:

$$
\text{score}(r, c) = 10\,(rc - n) + |r - c|
$$

The first term counts the empty cells. The second term measures the difference from a square. The factor 10 makes empty cells much more important than shape.

## Versions

Serpentine does not use the dictionary. Thus it does not use the dictionary version number. The seed text contains the version number. An example is `serpentine:v2:daily:haiku:2026-07-19`. Tests make sure that the letters of each poem stay connected on the grid.
