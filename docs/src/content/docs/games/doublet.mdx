Doublet is a domino game. The game gives you dominoes with two letters. You put the dominoes on a board. Each line of two letters or more must make a word. Only one arrangement of the dominoes is correct.

## How to play

1. Move a domino to the board.
2. Turn the domino if it is necessary. Each domino has four possible positions.
3. Continue until all the lines make correct words.

The game has three difficulty levels. Easy boards have 6 to 8 cells. Medium boards have 10 to 12 cells. Hard boards have 16 cells. Each board has an even number of cells. This condition is necessary for a full set of dominoes.

Your rank increases at 25, 50, 75, and 100 percent of the dominoes. The ranks are Placed, Arranged, Fitted, and Solved.

## How the game makes a puzzle

The generator has a time limit of 500 milliseconds. It has a maximum of 200 tries. Each try has three steps. The code is in `src/games/doublet/engine/generator.ts` and `boards.ts`.

### Step 1: Fill the board with words

The generator finds each line of two cells or more. These lines are the word slots. The generator fills the slots with words. It fills the most difficult slots first. It examines a maximum of 40 words for each slot. After each word, it makes sure that the other slots can still get a word. If a slot cannot get a word, the generator removes the last word.

### Step 2: Cut the board into dominoes

The generator connects the cells in pairs. Each pair is one domino. The generator always starts with the first free cell. It connects this cell with a random adjacent cell. If a connection is not possible, the generator goes back one step. The maximum is 50,000 steps.

### Step 3: Make sure that only one solution is possible

The generator then solves the puzzle again as a player. It puts each remaining domino on the first free cell in each possible position. After each domino, it examines the lines:

- Each line that is not complete must have a possible word.
- Each line that is complete must be a correct word.

Two solutions are the same when the letters on the board are the same. The generator keeps the puzzle only when one solution is possible. The maximum is 500,000 steps. If the search does not complete in the limits, the generator removes the puzzle.

### If the generator is not successful

The generator then tries the first board shape again with four times more time. If this try is also not successful, the generator gives the best available puzzle. This puzzle possibly has more than one solution. Thus the game does not stop.

## The mathematics

### Three hard problems in one puzzle

Each Doublet puzzle composes three problems that are hard in the general case:

1. **Crossword fill** is a constraint satisfaction problem. It is NP-hard in general.
2. **The domino cut** is a perfect matching in the grid graph of the board. The cells are the nodes. Two adjacent cells make an edge. A perfect matching pairs all the nodes. An even number of cells is a necessary condition. Thus each board has an even count.
3. **The uniqueness proof** examines all the possible placements. This count grows exponentially with the number of dominoes.

Small boards make all three problems fast. The largest board has 16 cells and 8 dominoes.

### Symmetry elimination

The matching search always extends the first free cell. This rule is important. Without it, the search examines the same matching in many different orders. With it, each matching occurs in exactly one branch. The uniqueness search uses the same rule for the dominoes.

### What "one solution" means

Two dominoes with the same two letters can change positions. The board then looks the same. These placements are not different solutions. Thus the generator compares the final letter grids, not the domino positions:

$$
\text{solutions} = \big|\{\, G(p) : p \text{ is a correct placement} \,\}\big|
$$

Here $G(p)$ is the letter grid of the placement $p$. The generator accepts the puzzle only when this count is exactly one.
