## The games

<div class="wg-card-grid">
  <HubCard game="polygram" title="Polygram" href="/docs/games/polygram/"
    accent="light-dark(#b91c1c, #f87171)">
    Make words from the letters of a polygon. When you find all the words, the
    polygon becomes larger.
  </HubCard>
  <HubCard game="crosshatch" title="Crosshatch" href="/docs/games/crosshatch/"
    accent="light-dark(#0c7d84, #3ddbd9)">
    A small crossword frame with given letters. Find all the words that agree
    with the frame.
  </HubCard>
  <HubCard game="backwords" title="Backwords" href="/docs/games/backwords/"
    accent="light-dark(#a21caf, #e879f9)">
    Put letters against a mirror. The mirror shows the remaining letters.
  </HubCard>
  <HubCard game="doublet" title="Doublet" href="/docs/games/doublet/"
    accent="light-dark(#92400e, #fbbf24)">
    Put letter dominoes on a board. Each line must make a word. Only one
    arrangement is correct.
  </HubCard>
  <HubCard game="serpentine" title="Serpentine" href="/docs/games/serpentine/"
    accent="light-dark(#4d7c0f, #a3e635)">
    Draw one continuous line through each cell of a grid. The line shows a
    hidden poem.
  </HubCard>
  <HubCard title="Daily puzzles" href="/docs/games/daily-puzzles/">
    Each device makes the same puzzle each day. A seed, quality limits, and
    version numbers do this. No server is necessary.
  </HubCard>
</div>
